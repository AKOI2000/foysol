# Foysol Consulting Website

Corporate website developed for Foysol Consulting to present their consulting services, company profile, and professional offerings.

The website provides potential clients with clear information about the company's services and allows them to easily reach out for business inquiries.

---

## Features

- Responsive business website
- Service and company information sections
- Clean UI with reusable React components
- Mobile-friendly layout
- Optimized performance

---

## Tech Stack

Frontend
- React
- Sass
- HTML
- CSS

Deployment
- Vercel

---

## Live Website

https://foysolconsulting.com

---

## Purpose of the Project

The goal of this project was to build a modern and professional website that strengthens the company's digital presence and improves accessibility for potential clients.
